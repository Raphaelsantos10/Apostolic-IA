# Fluxos essenciais do MVP

## Fluxos obrigatórios

### Começar sem conta

Início → preferências essenciais → catálogo permitido → aula demonstrativa →
resumo → continuar localmente ou conhecer os benefícios da conta.

### Retomar estudo

Início → continuar estudo → ponto guardado → concluir unidade → resumo e
próxima ação.

### Explorar curso

Cursos → filtros simples → detalhe → módulos → aula disponível.

### Criar conta futuramente

Convite opcional → benefícios e privacidade → cadastro → verificação →
preferências de sincronização → confirmação.

### Gerir dados futuramente

Mais → conta e privacidade → exportar ou excluir → confirmação de identidade →
explicação das consequências → conclusão auditável.

## Estados obrigatórios por tela

- **Carregando:** informar atividade sem bloquear tecnologias assistivas.
- **Vazio:** explicar por que não há conteúdo e oferecer uma ação útil.
- **Erro:** explicar em linguagem simples, preservar dados e permitir tentar
  novamente.
- **Offline:** distinguir conteúdo disponível de funções que exigem rede.
- **Sem autorização:** explicar o limite sem revelar dados protegidos.
- **Planejado:** não usar controles que pareçam funcionais.

## Navegação responsiva

- Telemóvel: barra inferior com até cinco destinos.
- Tablet: barra lateral recolhível ou navegação inferior conforme espaço.
- Web: navegação lateral ou superior com a mesma ordem conceitual.
- Teclado: ordem lógica, foco visível e retorno previsível.
- Leitor de tela: rótulos claros, regiões e títulos hierárquicos.

## Métricas futuras

Medições devem ser agregadas e proporcionais: início do primeiro estudo,
conclusão da unidade, retorno voluntário e abandono por etapa. Não registrar
conteúdo de anotações, orações ou perguntas sensíveis como telemetria comum.
