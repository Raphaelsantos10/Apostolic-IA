# Protótipo responsivo

## Executar

No Git Bash, a partir da raiz do repositório:

```bash
cd prototype
python -m http.server 4173
```

Depois abrir <http://localhost:4173>. Para encerrar, voltar ao Git Bash e
pressionar `Ctrl+C`.

Também é possível abrir `prototype/index.html` diretamente, mas o servidor local
representa melhor a futura experiência web.

## Escopo demonstrado

- Início com continuidade e recomendação editorial.
- Cursos com cartões demonstrativos.
- Bíblia como área planejada e bloqueada até licenciamento.
- Progresso local demonstrativo.
- Mais com preferências e informações do protótipo.
- Temas claro, escuro, sépia e sistema.
- Navegação responsiva e acessível por teclado.

## Breakpoints conceituais

- 320 a 767 px: telemóvel, barra de navegação inferior.
- 768 a 1023 px: tablet, painel lateral compacto.
- 1024 px ou mais: web, painel lateral ampliado.

O conteúdo adapta-se ao espaço disponível; os breakpoints não representam
modelos específicos de dispositivos.

## Limitações

- Dados e progresso são apenas demonstrativos.
- A troca de telas ocorre no navegador sem roteamento real.
- Não há autenticação, persistência de estudo ou sincronização.
- Não há alegação de conformidade WCAG; trata-se de base para testes futuros.
- O protótipo não deve ser publicado como produto final.
