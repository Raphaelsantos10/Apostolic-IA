# Sprint 023 — Jogos bíblicos e revisão inteligente

## Estado

Concluída após validação e incorporação do PR nº 25.

## Objetivo

Entregar jogos bíblicos pedagógicos, revisão inteligente e dificuldade adaptativa sem competição espiritual ou substituição do estudo responsável.

## Escopo

- sessões de jogos bíblicos;
- perguntas baseadas em conteúdo aprovado;
- tentativas, respostas e explicações;
- revisão inteligente de erros;
- dificuldade adaptativa por desempenho;
- progresso individual e privado;
- limites antiabuso e pontuação pedagógica;
- interface responsiva e acessível.

## Critérios de aceite

- [x] Utilizador inicia e conclui uma sessão de jogo.
- [x] Perguntas utilizam somente conteúdo publicado e aprovado.
- [x] Respostas apresentam correção e explicação.
- [x] Erros alimentam uma fila privada de revisão.
- [x] Dificuldade adapta-se sem punir ou rotular o utilizador.
- [x] Pontos representam aprendizagem verificável.
- [x] Dados pessoais e tentativas possuem RLS.
- [x] Limites reduzem automação e abuso.
- [x] Banco, testes, typecheck e build aprovados.
- [x] Inspeção visual aprovada.
- [x] Pull Request incorporado à `main`.

## Segurança pedagógica

O jogo reforça aprendizagem e revisão. Não mede fé, chamado, espiritualidade ou valor pessoal.
