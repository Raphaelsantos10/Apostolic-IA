# Sprint 017 — Aulas em texto, imagem, áudio e vídeo

## Estado

Concluída; aguardando incorporação do Pull Request.

## Branch

`sprint/017-aulas-multimidia`

## Objetivo

Implementar a estrutura de aulas multimédia vinculadas aos módulos publicados.

## Escopo

- aulas em texto autoral;
- imagens com licença, crédito e texto alternativo;
- áudio com transcrição;
- vídeo com legendas e transcrição;
- ordem das aulas dentro dos módulos;
- estados editoriais e publicação controlada;
- RLS para leitura e manutenção editorial;
- interface responsiva e acessível;
- testes, documentação e evidências.

## Critérios de aceite

- [x] Somente aulas publicadas de módulos publicados ficam visíveis.
- [x] Texto é apresentado com estrutura semântica.
- [x] Imagens exigem texto alternativo e licença registrada.
- [x] Áudio possui transcrição.
- [x] Vídeo possui legendas e transcrição.
- [x] Ordem das aulas é preservada.
- [x] RLS bloqueia alterações não autorizadas.
- [x] Testes, typecheck e build estão aprovados.
- [x] README representa corretamente o estado após o merge.

## Propriedade intelectual

Não serão copiados nomes, apostilas, imagens, áudios, vídeos ou materiais de
seminários existentes. Todo recurso externo exigirá licença documentada.
