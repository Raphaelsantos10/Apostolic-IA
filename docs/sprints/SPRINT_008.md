# Sprint 008 - Protótipo responsivo para telemóvel, tablet e web

## Estado

✅ Concluída - incorporada à `main` pelo Pull Request 9 em 24 de julho de 2026.

## Objetivo

Transformar a jornada, arquitetura da informação, design system e requisitos de
acessibilidade em um protótipo navegável local para validar estrutura,
responsividade e temas antes da implementação tecnológica definitiva.

## Entregas

- Protótipo estático navegável.
- Layout responsivo para telemóvel, tablet e web.
- Temas claro, escuro, sépia e preferência do sistema.
- Navegação principal com cinco destinos.
- Estados demonstrativos de conteúdo e funcionalidades planejadas.
- Instruções de execução local.

## Critérios de aceite

- O protótipo abre localmente sem instalar dependências.
- Funciona a partir de 320 CSS px sem rolagem horizontal indevida.
- Navegação adapta-se entre barra inferior e painel lateral.
- Teclado alcança todos os controles interativos.
- Foco é visível nos três temas.
- A preferência de tema é guardada localmente.
- Texto pode ser ampliado sem perda da ação principal.
- Recursos ainda inexistentes aparecem como demonstração ou planejados.
- Não contém textos bíblicos, imagens ou materiais externos não licenciados.
- Não é confundido com aplicação pronta para produção.

## Fora do escopo

- Backend, conta real, banco de dados e sincronização.
- Conteúdo bíblico protegido.
- IA real, áudio, vídeo ou pagamentos.
- Métricas, certificados e gamificação funcionais.
- Publicação em produção.
