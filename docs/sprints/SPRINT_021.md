# Sprint 021 — Gamificação saudável

## Estado

Em andamento na branch `sprint/021-gamificacao-saudavel`.

## Objetivo

Incentivar constância e aprendizagem verificável com pontos, níveis, metas,
sequência, conquistas e missões, sem medir fé ou espiritualidade.

## Critérios de aceite

- [x] Pontos têm origem verificável e idempotente.
- [x] Cliente não define livremente a pontuação.
- [x] Níveis são pedagógicos e limitados.
- [x] Sequência não aplica punição espiritual.
- [x] Conquistas dependem de pontos ou constância.
- [x] Missões mostram progresso real.
- [x] Dados pessoais são privados por RLS.
- [x] Rankings e práticas espirituais ficam fora do escopo.
- [x] Banco, seed e testes pgTAP aprovados.
- [x] Typecheck, build e inspeção visual aprovados.
- [ ] Pull Request aprovado e incorporado à `main`.

## Entregas realizadas

- razão de pontos auditável;
- perfil com níveis e sequências;
- conquistas e missões;
- sincronização segura no banco;
- painel responsivo de jornada;
- documentação de limites éticos.

## Validação

Banco, 81 testes, typecheck, build e inspeção visual aprovados.

## Limitações conhecidas

- não há ranking público;
- missões são editoriais e não expiram nesta sprint;
- recuperação e descanso avançados serão ampliados posteriormente.

## Próximo passo

Validar a Sprint 021 e preparar o Pull Request.
