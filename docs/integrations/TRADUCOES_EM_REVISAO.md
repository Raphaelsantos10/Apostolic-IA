# Traduções bíblicas recebidas — revisão de licença

Em 1 de agosto de 2026 foram validados ficheiros JSON completos (66 livros) para ARA, ARC, JFAA, KJA, KJF, NAA, NTLH e NVI.

Os ficheiros não incluem metadados de licença, autorização de distribuição ou atribuição editorial. Por isso, o texto dessas traduções não foi copiado para a aplicação nem disponibilizado publicamente. A interface apresenta os códigos como “aguardando licença”.

Para ativar uma tradução é necessário registar: titular/editor, texto da licença ou contrato, atribuição obrigatória, permissão de distribuição web, permissão offline e permissão de síntese de voz. Até lá, a versão completa ativa continua sendo Almeida 1911, em domínio público.
