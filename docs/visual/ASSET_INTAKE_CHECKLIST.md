# Checklist de entrada de ativo

## Identificação

- [ ] ID único atribuído.
- [ ] Título e descrição registrados.
- [ ] Tipo e finalidade definidos.
- [ ] Arquivo-fonte preservado.

## Direitos

- [ ] Criador e titular identificados.
- [ ] Origem registrada.
- [ ] Licença ou autorização arquivada.
- [ ] Uso comercial, edição e distribuição confirmados.
- [ ] Plataformas, territórios e prazo confirmados.
- [ ] Atribuição e avisos registrados.
- [ ] Uso offline e em miniaturas confirmado.

## Revisão

- [ ] Revisão editorial.
- [ ] Revisão doutrinária quando aplicável.
- [ ] Revisão histórica ou cartográfica quando aplicável.
- [ ] Revisão de privacidade e dignidade.
- [ ] Revisão de acessibilidade.
- [ ] Revisão de marcas e elementos de terceiros.
- [ ] Proveniência de IA registrada quando aplicável.

## Preparação

- [ ] Metadados sensíveis removidos.
- [ ] Texto alternativo ou marcação decorativa definida.
- [ ] Dimensões e variantes documentadas.
- [ ] Integridade e checksum registrados.
- [ ] Localizações de uso rastreáveis.
- [ ] Data de revisão ou expiração definida.

## Decisão

- [ ] Aprovado, aprovado com limites ou bloqueado.
- [ ] Responsável e data registrados.
