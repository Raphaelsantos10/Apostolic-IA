# Biblioteca visual

Esta pasta receberá somente ativos aprovados pelo processo documentado em
`docs/visual/`.

## Estrutura futura

- `source/`: matrizes próprias e preservadas; não publicadas diretamente.
- `images/`: imagens informativas aprovadas.
- `illustrations/`: ilustrações próprias ou licenciadas.
- `icons/`: ícones originais e acessíveis.
- `maps/`: mapas e camadas com fontes documentadas.
- `generated/`: variantes derivadas reproduzíveis.

Pastas serão criadas quando houver um primeiro ativo aprovado. Arquivos de
licença e evidência não devem conter dados pessoais desnecessários nem contratos
confidenciais em repositório público.

## Registro

O controle central está em [ASSET_REGISTER.md](ASSET_REGISTER.md). A presença de
um arquivo nesta pasta não substitui aprovação no registro.
