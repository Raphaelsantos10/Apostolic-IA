# Instalação - Sprint 002

Esta sprint contém apenas documentação.

1. Confirmar a branch `sprint/002-requisitos-mvp`.
2. Aplicar os arquivos na raiz do repositório.
3. Executar `bash scripts/validate-repository.sh`.
4. Rever `git status` e `git diff --check`.
5. Fazer commit e push.

Não existem dependências, migrações ou build executável.
